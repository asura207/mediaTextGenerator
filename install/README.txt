================================================================================
  TransM - AI Subtitle Studio 비개발자용 원클릭 간편 설치 및 사용 가이드
================================================================================

1. 처음 설치할 때 (원클릭 설치)
--------------------------------------------------------------------------------
   'install.bat' 파일을 더블 클릭하여 실행하세요.

   1) 화면의 안내에 따라 [1] 또는 [2] 번호를 누르시면 됩니다.
   2) 데이터베이스 선택:
      - [1] DB 서버 없음: 별도 DB 설치 없이 컴퓨터 내 파일(SQLite)로 초간단 자동 저장 (추천!)
      - [2] DB 서버 있음: 보유 중인 PostgreSQL 접속 정보 입력 -> 연결 테스트 후 자동 테이블 생성
   3) AI 엔진 선택:
      - [1] 로컬 LLM (Ollama): 내 컴퓨터 사양(RAM, 그래픽카드)에 맞춘 최적 모델 자동 추천
      - [2] 클라우드 LLM: OpenAI(GPT-4o), Anthropic(Claude), Google(Gemini) API 키 연동
   4) 설치가 끝나면 바탕화면에 바로가기 아이콘이 자동 생성됩니다!


2. 평소에 실행할 때
--------------------------------------------------------------------------------
   다음 중 편한 방법 하나로 실행하시면 됩니다:
   - 바탕화면의 [TransM - AI Subtitle Studio] 아이콘 더블클릭
   - 또는 프로젝트 폴더의 'start.bat' 더블클릭
   - 또는 본 install 폴더의 'start_transm.bat' 더블클릭

   잠시 후 웹 브라우저가 자동으로 열리며 자막 제작 화면이 나타납니다:
   - 웹 주소: http://localhost:5173 (또는 http://localhost:8000)


3. 주요 구성 파일 안내
--------------------------------------------------------------------------------
   - install.bat                 : 비개발자 원클릭 통합 설치 및 설정 마법사
   - setup_installer.py          : 단계별 대화형 하드웨어 감지 및 환경설정 프로그램
   - init_database.py            : 데이터베이스 테이블 생성 및 무결성 검증 도구
   - start_transm.bat            : 설치 후 원클릭 실행 런처
   - create_desktop_shortcut.vbs : 바탕화면 바로가기 아이콘 생성 스크립트


4. 시스템 권장 환경
--------------------------------------------------------------------------------
   - 운영체제 : Windows 10 / 11 (64비트)
   - 파이썬   : Python 3.10 이상 (https://www.python.org - 설치 시 Add to PATH 필수 체크)
   - 로컬 AI  : Ollama (https://ollama.com - 로컬 LLM 사용 시)
   - 그래픽   : NVIDIA GeForce RTX 시리즈 (CUDA 가속 지원, CPU만 있어도 구동 가능)
================================================================================
